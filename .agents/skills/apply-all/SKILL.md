# Apply All

На входе получи имя OpenSpec change.

1. Прочитай proposal/spec/tasks указанного change.
2. Определи зависимости и порядок implementation tasks.
3. Для каждой ещё не выполненной задачи:
   - создай новый отдельный task/fork;
   - не передавай историю выполнения предыдущих задач;
   - передай только:
     - текущую implementation task;
     - путь к OpenSpec change;
     - релевантные требования из spec;
     - инструкции AGENTS.md;
   - попроси реализовать только эту задачу;
   - потребуй запустить релевантные тесты/линтер;
   - дождись завершения.
4. После завершения задачи:
   - проверь diff;
   - проверь, что acceptance criteria выполнены;
   - отметь task выполненной в tasks.md;
   - только затем переходи к следующей.
5. После всех задач:
   - запусти полный набор релевантных проверок;
   - проверь реализацию относительно всей spec;
   - выдай краткий итог и найденные проблемы.

Не переиспользуй одного implementation-agent для нескольких задач.
Не запускай зависимые implementation tasks параллельно.
