Архивировано 11 ноября 2026 года по запросу пользователя. Внешняя часть задачи 7.3
отменена пользователем из-за отсутствия прав записи в исходную доску и остаётся
непроверенной. Архивирование не подтверждает выполнение этого сценария.
Локальный финальный прогон: 407/407 тестов; lint, typecheck, build и строгая
валидация спецификаций успешны.

Статусы задач отмечаются после проверки результата. Этот файл не является отчётом о тестах сайтов. Правила и критерии — в `design.md` и шести `specs/*/spec.md`; идентификаторы сценариев ниже ссылаются на них. Каждая задача включает адресные проверки своей области; assertions и сообщения ошибок тестов — на английском. Пользовательские сценарии проверяются через CLI, без добавления HTTP API и отдельных инфраструктурных тестов.

Зависимости этапов: **1 → 2 → 3 → 4 → 5 → 6 → 7**. Задачи внутри этапа выполняются по указанным зависимостям. Неподтверждённая возможность внешнего интерфейса блокирует зависимые задачи, а не заменяется выдуманным селектором, API или фиктивным успехом. Изменения вне MVP требуют отдельного согласования.
